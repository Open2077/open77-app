# Served Hub guest browser acceptance

`scripts/check-hub-browser.mjs` uses native Chrome DevTools Protocol against an
**already-running** local website and its real configured master. It starts no
Next process, proxy or mock API. Supply an existing published project's current
slug and exact title. Use a fixture with at least two approved, accessible images
and descriptive alt text to cover the entire gallery keyboard journey.

```powershell
node scripts/check-hub-browser.mjs http://127.0.0.1:3000 auto-taxi "Auto Taxi" --require-gallery
```

The command accepts only explicit HTTP loopback origins and creates its own
temporary browser profile and ephemeral loopback debugging port. It never
attaches to an existing browser. `CHROME_PATH` can select an installed Chrome or
Edge executable. Page, CDP, image and startup waits have bounded deadlines. Cleanup
closes only the owned browser and removes only its generated temporary profile.

At 390, 768 and 1440 pixels it verifies the actual fetched SSR H1, hydrated title,
production canonical URL, horizontal overflow, guest account links and interaction
gates, and read-only discussion inputs. For actual media it checks descriptive alt
text, Enter activation, initial close-button focus, reverse-Tab containment, left
and right navigation when two images exist, real image loading, Escape dismissal
and restored trigger focus. It fails on browser console errors or uncaught
exceptions. Project, discussion and applicable gallery screenshots plus a JSON
receipt are written under ignored `artifacts/hub-browser/<timestamp>/`.

Without `--require-gallery`, missing media is explicitly recorded as **not
present**, not passed gallery coverage. A single image does not prove navigation.
No authenticated session, upload, vote, comment, report, download grant or file
delivery is created. Normal page-view telemetry generated by the product can still
be recorded. This guest journey does not replace creator/admin, cross-user,
download-integrity, private-draft authorization or real-game acceptance gates.

The runner and argument guards were syntax/guard-validated on 2026-09-11:

```powershell
node --check scripts/check-hub-browser.mjs
node scripts/test-hub-browser-guards.mjs
```

**Served-browser execution remains unperformed.** Website startup was previously
rejected by automatic command approval; this script does not retry or bypass that
rejection. Run it only when an authorized website is already available, and attach
its actual receipt/screenshots before claiming this acceptance gate passed.
