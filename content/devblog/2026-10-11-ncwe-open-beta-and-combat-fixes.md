OPEN//77 had a focused but useful day: the team shipped a client usability fix, improved melee reliability, and opened the Night City World Editor beta to everyone. For players waiting on **Cyberpunk 2077 multiplayer** and server owners planning a **Cyberpunk 2077 RP server**, these are the kinds of updates that make the platform feel more real and more usable.

## Better everyday play in the client

The in-game WebUI pause menu is now working properly again for players who use five-button mouse bindings. That sounds minor at first glance, but control edge cases matter a lot in a game where players expect every menu and input to respond cleanly.

When basic interactions fail, the whole experience feels rougher than it should. Restoring this behavior means one less friction point in normal play sessions, especially for players with more customized setups.

This change is also part of the newly published Stable 136 client release, so it is not just a fix sitting in limbo. It is now part of the stable player-facing build.

## Melee combat gets more reliable

The other important gameplay improvement today is on the melee side. The latest update improves how melee attack windows are tracked across tiny timing gaps and combo transitions, with a specific pass for the Mantis melee profile.

The practical result is simple: close-range combat should behave more consistently. Swings and combo chains are less likely to feel like they dropped an interaction for no good reason. That is especially valuable in a **Cyberpunk 2077 co-op** or **Cyberpunk 2077 online** setting, where combat clarity matters even more because players are reacting to each other and to shared action.

This is not a flashy new feature, but it is exactly the kind of systems work that helps combat feel solid instead of unpredictable. For anyone following OPEN//77 closely, this is the kind of progress that makes the eventual multiplayer experience more trustworthy.

## NCWE open beta is now live

The biggest broader ecosystem update today is for NCWE, the Night City World Editor. The editor is now in open beta, and it no longer asks for an account just to get in and start building.

That is a meaningful step for creators. Removing the access gate lowers the barrier for curious builders, mappers, and future server owners who want to experiment without going through account setup first. Signing in is still relevant for features like cloud saves and live collaboration, but the basic experience is now much easier to try.

For a project building toward **Cyberpunk 2077 dedicated server** support and custom multiplayer worlds, better access to tooling matters a lot. A healthy creator ecosystem does not come only from gameplay code. It also comes from making world-building tools easy to discover and easy to test.

## The website now puts the Map Editor front and center

To match the editor's open beta status, open2077.net now gives NCWE a much more visible home. The site added a dedicated landing page for the Map Editor, and the top navigation now features “Map Editor” in place of the older Workshop link.

That is a small website change with a clear message: the editor is no longer a hidden side project. It is becoming a first-class part of the OPEN//77 ecosystem.

For future community builders, this matters because discoverability matters. If a tool is hard to find, fewer people try it. If the site presents it clearly, more players and aspiring admins can understand that OPEN//77 is not only aiming for **Cyberpunk 2077 multiplayer mod** gameplay, but also for a modding and server-building platform around it.

## Small NCWE quality fix: elevators

NCWE also received a practical bug fix for elevators. Multi-door elevator cabins now open the correct doors toward their landings.

This is the kind of detail that sounds narrow until it breaks a scene. For map creators, environmental interactions need to match the space they built. Fixes like this help custom interiors and traversal setups feel believable and production-ready.

## Early server ecosystem support keeps growing

One more notable addition today: an official Top Serveurs addon was introduced for Open//77 servers. The addon is aimed at vote tracking and related server-side events.

That is more relevant to server owners than regular players right now, but it is still a good sign. A multiplayer platform grows faster when discovery, promotion, and community tooling start appearing early. It suggests the ecosystem around **Night City online** is slowly taking shape, not just the client itself.

## Why today matters

Today was not about giant cinematic reveals. It was about making OPEN//77 more usable from multiple angles: cleaner input behavior for players, more dependable melee combat, easier access to the world editor, and better visibility for tools that future server communities will rely on.

That combination is what progress often looks like in a real multiplayer project. One update makes the game feel better, another makes the tools easier to use, and another helps server owners prepare for what comes next. Step by step, OPEN//77 keeps turning the idea of CP2077 multiplayer into something more tangible.
