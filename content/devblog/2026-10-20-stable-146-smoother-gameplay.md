OPEN//77 shipped a small but meaningful stable update today. Stable build 146 follows the latest release with a client hotfix focused on two player-facing issues: frame stalls and underwear flicker, both of which can pull players out of the Cyberpunk 2077 multiplayer mod experience fast.

## Stable build 146 focuses on feel, not flash

The biggest news today is the new stable hotfix. Build 146 is aimed at improving how the game feels during normal play, with work targeting frame stalls and a visual bug that caused underwear flicker.

These are not headline-grabbing feature drops, but they matter a lot in a game built around immersion. A sudden frame hitch can make driving, combat, or simply moving through Night City feel rough. Visual glitches are just as damaging when the goal is a believable Cyberpunk 2077 online experience.

For players following OPEN//77, this kind of stable update is a good sign. It shows the team is still tightening up the basics that make Night City online feel smooth and consistent, not just chasing new systems.

## Client and server releases continue to move forward

Alongside the hotfix, the platform also published stable client and server build 145. After that, stable 146 went out as a client-side hotfix.

For future hosts planning a Cyberpunk 2077 dedicated server, this is the practical side of progress: official builds are being published, versioning is moving, and the release track is active. Even when a day is centered on fixes, having fresh stable releases available is important for confidence and compatibility.

That release rhythm is part of what turns a prototype into a platform. Players want smoother sessions. Server owners want clear, current builds they can trust.

## Better docs for custom clothing and movement systems

Today also included a documentation pass covering custom clothing, locomotion clips, and GameInstance-related access patterns.

This is less exciting for regular players in the short term, but it matters for creators building the future of OPEN//77. Better guides around clothing registration and persistence can make it easier to support custom character content. Documentation for locomotion clips helps resource creators work with movement and animation behavior more reliably. Expanded explanation around GameInstance access helps advanced developers understand how to connect to core game systems correctly.

For anyone hoping to see richer Cyberpunk 2077 RP server content over time, this kind of support work is valuable. Better documentation usually means faster iteration, fewer mistakes, and more community-made features reaching playable quality.

## Why this update matters

Today’s progress is a classic quality-of-life update. No massive reveal, no giant system debut—just a stable branch getting smoother where players will actually notice it.

That matters because every Cyberpunk 2077 co-op or multiplayer session depends on the basics feeling solid. Performance hitches and visible glitches can ruin the vibe quickly. Fixing them improves confidence in the build and makes each session feel closer to the experience players are waiting for.

At the same time, stronger documentation helps the broader OPEN//77 ecosystem mature. Stable releases help players and server owners. Better guides help creators. Both are necessary if OPEN//77 is going to grow into a real home for Cyberpunk 2077 multiplayer, RP, and dedicated servers.

## Looking ahead

The main takeaway from today is simple: stable 146 is here to smooth out rough edges that players can actually feel. That is exactly the kind of maintenance work a growing multiplayer platform needs.

As always, the exciting part is not just one hotfix by itself. It is the pattern behind it: active stable releases, visible fixes, and steady groundwork for creators building the next layer of the OPEN//77 experience.
