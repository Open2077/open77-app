**NCWE Studio 1.0.0 is available.** The Night City World Editor leaves beta with its first stable release for Cyberpunk 2077 2.5. It is free and open source, and no account is needed to build worlds.

[Download NCWE for Windows](/ncwe#download).

The release includes the world editor, Animation Studio, Population workspace, cloud saves, live collaboration and MCP integration. Worlds export as ArchiveXL mods or OPEN//77 resources; authored meshes can also be exported for World Builder.

## What is new in 1.0

- **Edit distant LODs up close.** World → Edit distant LODs isolates distant proxy meshes and keeps them visible as you approach. Select and delete them, save the project and export the changes, including Cyberpunk 2077 2.5 cooked generic proxies.
- **Restore original game objects.** Revert modifications and replacements from the Edit menu, Inspector or Outliner, including changes saved before closing and reopening a project. Restoration supports Undo/Redo.
- **Create faces with F.** In mesh edit mode, select coplanar boundary vertices and press F. Four corners create a triangulated quad. Invalid selections leave the mesh unchanged.
- **Place ENV reflection probes.** Browse the game's probe resources, place them and edit their settings and influence volumes. Probe settings persist in projects and ArchiveXL/OPEN//77 exports.
- **Build 3D text.** Add → 3D text assembles the game's Konpeki letter meshes into a group, with adjustable height, spacing, multiple lines and alignment. Creating the group is one undo step.
- **Fit UVs to textures.** Fit to texture preserves proportions; Fill texture stretches both axes. Cube projection and Unwrap are easier to reach from the UV editor.

## Editing improvements and fixes

Undo/Redo now remembers object selections. Deselect an object to inspect your edit, then undo to restore the selection. Automatic selections after edits belong to the same undo step as the edit itself. Selection changes do not mark a project as modified or send a world edit to collaborators.

Edited terrain now remains visible after a brush stroke. The UV editor's Material background shows the custom diffuse texture assigned to the object and refreshes when that material changes. Automation picking in LOD mode matches the visible geometry.

The new interface controls are translated into French, Spanish, Japanese, Polish and Brazilian Portuguese.

## Updating from the beta

Close NCWE, download the 1.0.0 archive and extract it to a new folder. Start **NCWE.Studio.exe** from that folder. Your settings and sign-in remain in place, and your projects stay where you saved them. The archive includes .NET, the Windows App SDK, the MCP server and the English changelog.

NCWE requires Windows 10 or 11, a DirectX 11 graphics card and your own Cyberpunk 2077 2.5 installation. To play exported mods, install RED4ext and the [OPEN//77 build of ArchiveXL 1.28.0](https://github.com/Open2077/archive-xl/releases/tag/v1.28.0-open77.1).

## Tool behavior to keep in mind

A distant proxy can combine several objects or a whole area: deleting it removes that combined distant representation. ENV probes reuse baked game resources; the editor displays their influence volumes, and reflection and lighting results should be checked in game. The text generator supports A–Z, 0–9, spaces, line breaks, dash, slash and underscore.

The release passed 486 automated tests, with 31 optional tests skipped for unavailable fixtures or services. Terrain editing, custom diffuse previews, face creation, LOD deletion and restoration, probe settings and grouped text were also checked with installed game assets through project saves and exports.
