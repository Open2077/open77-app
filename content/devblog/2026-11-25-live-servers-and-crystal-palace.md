Today’s work touched two things players will notice immediately: the public server directory is now more reliable, and Crystal Palace got a serious immersion upgrade. For anyone following **Cyberpunk 2077 multiplayer** and the road to a real **Cyberpunk 2077 online** experience, this was a good one.

## Public server listings now behave properly

A frustrating edge case in the platform backend could make a live server disappear from the public directory if that same server also had an approved “Upcoming” announcement attached to it. That was obviously bad for players trying to find a server, and even worse for server owners who were online and healthy but suddenly absent from the list.

That logic has now been corrected. If a server is live and actively reporting in, it stays listed publicly. An approved pre-launch announcement will no longer override the fact that the server is actually online.

This is not a flashy feature, but it matters a lot. A **Cyberpunk 2077 dedicated server** cannot build momentum if players cannot see it, and server owners should not need to worry that a promotional announcement might hide a running server.

## Crystal Palace gets proper voice, audio, and atmosphere

Crystal Palace kept moving closer to a believable playable location instead of just a cool concept. One of the biggest changes is Brendan: he now speaks his lines out loud in a smoother, more natural voice instead of feeling like a text-only interaction.

Just as important, the audio path was adjusted so players can actually hear him properly by default. That sounds simple, but it is the difference between “the NPC technically works” and “the NPC feels present in the world.” For a **Cyberpunk 2077 multiplayer mod**, details like this are what make shared spaces feel alive rather than scripted.

The same attention went into the station’s airlock experience. The Sky Port now uses more fitting airlock-style doors, with steam effects added around the seams to sell the idea of a pressurized, high-security orbital terminal.

## Smoother shared-world behavior in Crystal Palace

One multiplayer-specific improvement stands out here: airlock door visuals are now synced between players. Previously, one player could open a door and another player might not see that state correctly. That kind of mismatch breaks immersion fast in co-op and RP spaces.

Now everyone sees the same airlock state, which makes the space feel much more grounded for **Cyberpunk 2077 co-op** sessions and for future social or RP scenarios.

This is the kind of work that often gets underestimated from the outside. Beautiful spaces are one thing; making those spaces behave consistently across multiple players is what turns a build into a functioning multiplayer environment.

## New arrivals area makes the station feel real

The station’s round Sky Deck received a bigger structural pass as well. The area now includes three docks, arrival checkpoints, staff-facing entry points, and scanner setups inspired by a proper luxury spaceport arrival flow.

That matters because first impressions matter. If Crystal Palace is going to work as a destination in **Night City online**, the arrival sequence has to feel intentional. Players should understand immediately that they are entering a controlled, premium, high-status environment — not just walking into another generic interior.

The result is a stronger sense of place and a layout that better supports roleplay, guided events, and high-security storytelling.

## CCTV arrives, with safer behavior for live servers

Crystal Palace also gained a full CCTV feature set, including a bank of live security feeds displayed on the Head Admin Dome video wall. Sixteen camera views now help sell the idea that this is a monitored, high-value facility.

The interesting part is not just that cameras exist, but that the feature was made more resilient for real multiplayer use. Extra protection was added to prevent bad edge-case behavior from camera presentation logic, and a fallback viewing mode was introduced so the CCTV system still remains usable even when a player’s setup cannot handle remote camera rendering the normal way.

That is a good example of practical polish. In a **Cyberpunk 2077 RP server** environment, flashy systems only matter if they survive contact with real players and real hardware differences.

## A third lift rounds out the main core

The station also received a new West Lift, giving the main core a third elevator shaft. On paper, that sounds like a small world update. In practice, it helps the location feel more like a premium orbital complex designed for traffic, staff flow, and believable movement.

These kinds of additions matter over time. Multiplayer spaces become memorable when navigation, scale, and architecture all support the fantasy.

## Why this update matters

This was a strong “make it usable, make it believable” day for OPEN//77. The public directory fix protects visibility for live communities, while Crystal Palace keeps evolving from an impressive build into a more convincing multiplayer destination.

If you are watching OPEN//77 for **CP2077 multiplayer**, today’s changes are a good snapshot of the project’s direction: fewer rough edges, better shared-world behavior, and more spaces that feel like they belong in Cyberpunk 2077 instead of sitting beside it.
