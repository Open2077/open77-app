Today’s update focused on better building blocks for OPEN//77. The headline feature is Freeroam 0.7.0, which now includes Race, PvP, and animation support, while the server stack also gained a safer way for resources to share features with each other. For anyone following the future of **Cyberpunk 2077 multiplayer** and custom servers, this is a meaningful step toward more complete game modes.

## Freeroam grows into a real server starter

Freeroam has always been an example resource, but with version 0.7.0 it starts looking a lot more like a serious foundation for live servers.

The new release integrates **Race** features directly into Freeroam. That gives server owners a ready-made activity to build around, whether the goal is casual street racing, organized events, or a competitive server loop. Instead of assembling everything from scratch, creators now have an example that already includes a recognizable gameplay pillar.

Freeroam 0.7.0 also adds **PvP** support. That opens the door to more action-focused servers and gives builders another core system they can expand with rules, arenas, scoring, or event logic. Even for mixed-purpose servers, built-in PvP support makes Freeroam a much stronger sandbox than before.

The third big addition is **animation support**. That matters because player expression is a huge part of making **Night City online** feel alive. Animations help with social moments, roleplay scenes, event hosting, and simple quality-of-life interactions. Even before launch, this kind of feature helps show what the world can feel like once more players are sharing it.

## Better foundations for Cyberpunk 2077 dedicated server builders

Alongside the Freeroam update, the server now supports **isolated cross-resource exports**.

That phrase is more technical than the effect. In practical terms, it means one server resource can expose functionality to another resource in a cleaner and safer way. For server owners and developers, that makes it easier to split a project into separate pieces such as jobs, events, racing systems, admin tools, or RP mechanics without everything becoming tightly tangled together.

This matters for the future of **Cyberpunk 2077 dedicated server** hosting in OPEN//77. Healthy server ecosystems need modular systems. Builders want to reuse features, replace components, and combine multiple gameplay ideas on one server. Cleaner resource-to-resource communication is a big part of making that possible.

Players may not feel this change directly today, but they will feel the results later through better stability, easier customization, and faster feature development on community servers.

## New documentation for animations and resource exports

We also published new documentation covering the animation APIs and the new cross-resource server exports.

Good docs are not flashy, but they have a direct impact on how fast community content appears. Clear examples reduce guesswork, help new builders get started, and make advanced features more approachable. That is especially important for a project aiming to support everything from casual hangout servers to a full **Cyberpunk 2077 RP server** setup.

For server owners, this means less time hunting for answers and more time actually building. For players, it means the ecosystem around OPEN//77 can grow faster.

## Why this update matters

This was not a launcher patch or a giant public-facing gameplay reveal. It was a platform-strengthening day, and those days are important.

Freeroam 0.7.0 gives creators more to work with immediately: races, PvP, and animations in one example package. The new cross-resource export system gives those creators a better way to organize larger ideas. The docs help turn both additions into something people can actually use.

That combination is exactly how a **Cyberpunk 2077 multiplayer mod** becomes more than a tech demo. You need activities, expression, and solid server architecture. Today moved all three forward.

If you are waiting to play, the exciting part is what these pieces lead to: more varied servers, more social interactions, and more reasons to stay in the city once OPEN//77 opens up further. If you are planning to host, today’s update gives you a stronger starting point and cleaner tools for building your own corner of Night City.
